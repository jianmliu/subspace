# Proof of Resident Weights

**显存驻留共识：让区块链的稀缺资源与 AI 推理硬件合一**

白皮书 v1.0 · 2026 年 8 月

---

## 摘要

我们提出 Proof of Resident Weights（PoRW）：一种把 Nakamoto 式容量抽签共识的稀缺资源，从"SSD 上的唯一编码存储"替换为"经 TEE 证明驻留在 GPU 显存中的大模型原始权重"的共识机制。同一份显存字节既是共识抵押、又是可服务的推理权重——出块权与真实推理服务量挂钩（多劳多得），闲置显存自动获得挖矿收益下限，真实需求通过费用燃烧转化为共识安全预算。

PoRW 保留 Subspace 共识的成熟骨架（PoT 硬时钟、每 slot 挑战、容量加权抽签、solution range 难度调整），以双轨结构运行：**显存轨**承载热模型的推理容量市场，**存储轨**（原 Subspace PoAS）承载全部历史（含模型权重与 agent 记忆）的经济-概率性永存，并充当显存轨欺诈争议的最终仲裁层。配合每请求的推理 attestation，网络为链上 AI agent 提供"记忆永存 + 算力按需 + 输出可验证"的端到端生命周期底座。

核心工程假设已在 A100 80GB 上实测验证：驻留审计（sketch）以 72% HBM 峰值带宽流式执行，每 slot 审计一次 70GB 权重仅占用约 5% 带宽预算；审计规范在 CPU 解释器、GPU 后端与参考实现之间逐位一致；针对压缩伪造的攻击在可执行演示中全部失败。

## 1. 动机

### 1.1 共识资源与 AI 硬件的错配

工作量证明消耗专用算力（ASIC），权益证明消耗锁定资本，容量证明（Chia、Subspace）消耗存储空间。与此同时，全球最昂贵、增长最快的计算资源——GPU 显存与 HBM 带宽——服务于 AI 推理，却与任何主流共识机制无关。推理是显存驻留、带宽受限的工作负载：decode 每生成一个 token，都要把全部模型权重从 HBM 完整扫描一遍。

一个自然的问题：能否让共识的稀缺资源恰好就是 AI 推理占用的资源，使得"参与共识"与"提供推理服务"是同一件事？

### 1.2 为什么以 Subspace 为骨架

Subspace（Autonomys）的 Proof-of-Archival-Storage 提供了三件可直接继承的资产：

1. **PoT 硬时钟**：顺序 AES 迭代构成不可加速的时间源，每 slot（1 秒）产生全局挑战，杜绝快算未来挑战的 long-range 攻击；
2. **容量抽签与难度调整**：中签判定 `solution_distance ≤ solution_range/2`，全网难度自动跟随总资源量；
3. **DSN 归档层**：历史纠删码后由农民均匀随机抽样存储，"全网历史完整保存"是统计涌现性质，无需任何节点存全量。

PoRW 不重写这些，只替换"被审计的资源"。

## 2. 核心难题：不可能三角与 TEE 抉择

容量共识要求**每个参与者的副本唯一**（否则一份物理数据可应答任意多身份的审计，Sybil 攻击成立），Subspace 用农民公钥播种的唯一编码实现这一点。但模型权重必须以**原始格式**驻留显存才能喂给推理框架——密封编码后的字节推理引擎读不了；而"便宜可逆"的密封同样不行：解码便宜意味着按需编码也便宜，作弊者存一份原始数据即可现场伪造任意身份的"唯一副本"。

**不可能三角：推理可用（解码快）／副本唯一（按需重编码贵）／不额外占空间——纯密码学框架下最多取二。**

PoRW 的抉择：用 TEE 硬件证明换掉"密码学唯一性"这一角。GPU 机密计算（NVIDIA Hopper 起）提供设备内熔断的唯一身份密钥与代码度量——**一张物理卡就是防 Sybil 的计数单位**，权重得以保持原始格式。信任依赖被显式接受并工程化约束：NVIDIA 设备身份、Intel TDX / AMD SEV-SNP 机密虚拟机、经治理白名单的节点代码度量。第 4.5 节与第 9 节说明该信任在失效时如何被限定为**有界损失**而非无界伪造。

## 3. 架构总览

### 3.1 四个信任支柱

| 支柱 | 机制 | 证明什么 |
|---|---|---|
| **B · 设备证明** | CVM + GPU CC 远程证明，一卡一注册 | 真实唯一的物理设备，运行白名单代码 |
| **C · 驻留审计** | 挑战随机化的字粒度线性草图（sketch） | 权重字节真实驻留 HBM 且本 slot 被读取 |
| **D · 推理证明** | 每请求 attestation quote | 输出确由注册模型对该输入产生 |
| **PoT · 硬时钟** | 顺序 AES（继承 Subspace） | 挑战不可预测、响应期限客观 |

C 与 D 互补而不冗余：C 是挑战驱动、每 slot 发生、无请求也有——服务共识抽签（稀缺资源计量）；D 是请求驱动、有请求才有——服务费用市场（可验证收据）。两者绑定同一个模型承诺根 `R_W`。

### 3.2 双轨共识

出块奖励按治理参数分配给两条轨：

| 轨道 | 资源 | 机制 | 购买的东西 |
|---|---|---|---|
| **显存轨（PoRW）** | GPU 显存中的原始权重 | 本文第 4 节 | 热模型的推理容量 |
| **存储轨（PoAS）** | SSD 上的唯一编码历史碎片 | 原 Subspace 机制 | 全部数据的永存与终审 |

热权重住昂贵显存、历史与退役权重住廉价 SSD，各归其位；chiapos/KZG 唯一编码只在存储轨保留（那里没有"推理可用"的需求，不可能三角不成立）。

## 4. 显存轨：Proof of Resident Weights

### 4.1 核心观察与审计原语

推理 decode 本来就在每个 token 把权重完整扫过 HBM——共识想强制的行为，推理已经在做。审计只需对真实发生的读取做承诺。

权重按 4 KiB tile 划分，Merkle 根 `R_W` 登记链上。每 slot 由 PoT 挑战派生系数，节点对本 slot 推理**实际读取过**的 tile 集合 `C_t`（覆盖集：dense 模型忙时≈全集；MoE 下 = 实际激活的专家 + 共享层）计算草图：

```
r_i      = PRF(challenge, device_id, tile_i)      // 每 tile 种子
c_{i,j}  = PRF'(r_i, j) | 1                       // 每字系数，寄存器内生成，取奇
sketch_t = Σ_{i∈C_t} Σ_j  c_{i,j} · w_{i,j}       // 模 2^32 乘加
```

三个不可省略的构造细节，各对应一类已在原型中演示的攻击：

- **系数必须细到字粒度且每 slot 新鲜**。若 tile 内共用系数，sketch 坍缩为固定线性泛函的倍数——作弊者每 4096 字节 tile 只需存 4 字节摘要即可通过所有未来审计（1024 倍压缩，原型中有 100 个 slot 全部伪造成功的可执行演示）。字粒度 PRF 系数（murmur3 fmix32，约 6 条整数指令/字）使该攻击及"64 固定泛函 + 最小二乘重构"攻击全部失败。
- **系数取奇**。模 2³² 下偶系数会让字最高位的翻转以至多 1/2 概率逃逸检测；奇数乘子是双射，任意单比特篡改必然改变草图。
- **整数域、模加交换**。与浮点无关，跨卡跨驱动逐位确定；模加对任意分块与求和顺序不变——kernel 形状、launch 顺序、幂等并发写都不影响结果。

### 4.2 密码学硬边界与抽签权重

系数以 slot 为粒度，故 sketch 能证明的物理量上限是"**每 slot 每 tile 至少一次真实读取**"——读取次数、token 数等劳动强度密码学上不可证。抽签权重据此拆为两因子，各由能负责它的机制背书：

```
中签概率 ∝ |C_t|（覆盖门票）× m_t（服务量乘数）× √(有效质押)/√(上限)
           └ sketch 密码学背书 ┘ └ TEE 计量+包络封顶 ┘ └ 有界经济对齐（§6.3）┘
```

`m_t` 为"覆盖集被完整扫过的遍数"，由被度量的节点代码如实统计，并受**硬件包络**硬性封顶：`|C_t|×m_t ≤ 该卡型号带宽 × slot 时长`。即使 TEE 被完全攻破，单卡可虚报的票数也不超过其物理带宽上限——失效模式是有界通胀，不是无界伪造。

闲置的卡没有推理就没有票；理性策略是自跑负载（物理上趋同于带宽扫描）。协议不区分真实与自生成负载——自生成负载真实消耗带宽、买不到超过物理上限的票，它构成显卡的**收益下限**，真实服务的溢价由费用市场承担（§6）。

### 4.3 执行策略：跟随覆盖的定向扫描

A100 实测（§8）确立了执行策略。两种实现的税基不同：把 sketch 融合进推理 kernel 是**吞吐税、每 token 都交**（实测单次 GEMM 开销 2.7–8.7%）；对覆盖集做独立定向扫描是**带宽税、每 slot 只交一次**（1401 GB/s 下扫 70GB ≈ 50ms ≈ 5% slot）。由于协议每 slot 只认一次证明（§4.2），融合在每个 token 重复计算协议收不了货的东西——**定向扫描是主路线**：节点从路由遥测取 `C_t`，只扫这些 tile；零推理侵入、兼容一切推理后端（cuBLAS/CUTLASS/FlashInfer 无关）。kernel 融合保留为高保证加固模式（覆盖由密码学而非遥测背书），供 TEE 信任折扣场景选用。

### 4.4 验证栈

Solution 携带 `{device_id, model_id, sketch, coverage_bitmap, partials_root, m_t, sig}`，其中 `partials_root` 是 per-tile sketch 值的 Merkle 根（kernel 天然产出 per-tile 部分和），使一切欺诈证明降为**单 tile 粒度**——取回一个 tile 的字节、重算、对 Merkle 路径比对，O(4KiB)。

| 层 | 时机 / 成本 | 抓什么 |
|---|---|---|
| 0 · TEE 构造防线 | 前置 | 被度量的诚实代码不产出假数据 |
| 1 · 链上快速路径 | 每块，微秒级 | 注册 / 签名 / 模型登记 / 包络封顶 / 抽签数学 |
| 2 · 副本交叉核验 | epoch 抽样，≈免费 | 伪造 sketch：同模型设备权重就在自己 HBM 里，抽查 tile 重算，无需知晓对方推理输入 |
| 3 · 存储轨终审 | 挑战期，慢路径 | 孤本模型与一切争议的终局裁决（§5.3） |

**诚实边界**：本栈抓"驻留与覆盖造假"；`m_t` 的包络内虚报密码学不可抓。但其经济敞口有界且衰减：`m_t` 只影响区块奖励、不影响按请求结算且 D 支柱背书的服务费；包络封顶使谎报的最大收益仅为"省下未执行扫描的电费"（单卡百瓦级），对面是罚没与吊销；且随网络成熟、费用收入占比上升，这个唯一软点在总收入中的权重单调下降。

## 5. 存储轨：永存与终审

### 5.1 统计永存（继承 Subspace）

历史（含上架的模型权重、agent 记忆）纠删码为 piece（每 segment 任意半数可恢复），农民按自选规模存储**协议指派的均匀随机抽样**——无人存全量，每 piece 期望副本数 ≈ 全网质押空间 / 历史大小。永存是**经济-概率性保证**：通胀持续、存储成本下降快于历史增长，则副本数维持。我们不对外承诺密码学意义的"绝对永存"。

### 5.2 同一份权重的三种形态

存储轨"不可挑选碎片"与推理"需要完整权重"不冲突——推理热路径从不读存储轨：

| 形态 | 内容 | 谁选择 | 激励 | 用途 |
|---|---|---|---|---|
| VRAM 原始权重 | 完整、自选模型 | 农民自由挑 | 抽签 + 推理费 | 推理热路径 |
| 本地 SSD 完整副本 | 完整原始格式 | 农民自由囤 | 秒级重载 + 复活赏金 | 显存载入源、温层 |
| DSN 唯一编码碎片 | 均匀抽样 | 协议指派 | 存储轨奖励 | 永存 + 终审 |

上架 = 一次 DSN gather（重组 + 对 `R_W` 逐 tile 验证）→ 本地留完整副本 → 载入显存；此后重载走本地（秒级）。

### 5.3 存储轨即仲裁法庭

sketch 只依赖挑战系数 × 权重字节 × 覆盖集，而 DSN 碎片对 `R_W` 是规范字节——**任何存储轨农民都能检索含争议 tile 的 piece、重算并提交欺诈证明**。sketch 争议的最终裁决因此不依赖任何 VRAM 副本存在：副本交叉核验只是快速抓骗的优化，`min_replicas` 从安全参数降为服务参数。这是双轨结构的第二个协同（第一个是永存）。

### 5.4 热层驱逐的三个风险与补强

显存层是需求驱动的热缓存，非热点模型不保证有 VRAM 副本。三个风险各有机制：**冷启动延迟**——热/温/冷分层可查询，付费请求可附复活赏金，农民自发用本地 SSD 囤退役模型抢赏金，温层市场化形成；**孤本核验失效**——由存储轨终审兜底（上节）；**需求正反馈震荡**——注册集合内模型获得质押支付的保底权重 `max(需求权重, floor)`，权重调整加 EMA 滞后与驱逐冷却期。

## 6. 经济模型

### 6.1 代币飞轮

出块奖励发给的正是提供推理容量的资源，用同一代币给 agent 推理费计价构成闭环：

```
通胀补贴待机容量（收益下限）→ agent 付费推理 → 费用部分燃烧
→ 需求↑ 燃烧↑ 净通胀↓ → 显卡收益↑ → 容量↑
```

需求驱动安全（EIP-1559 式）；早期通胀自举容量，后期过渡到费用主导。三个必须守住的设计点：报价锚定算力成本、代币仅作结算资产（计价 ≠ 结算）；bond 退出延迟与长期驻留加成对冲死亡螺旋；质押配额（work-token）给代币与用量成正比的锁定需求。

### 6.2 模型准入：质押上架 + 需求跟随权重

初期治理白名单集中副本；成熟期任何人质押 + 上架费 + 许可证声明即可提案。核心机制：**每模型奖励权重 ∝ 其付费推理费用燃烧量的滑动平均**——无人使用则权重衰减、农民腾显存给热模型；刷量须真实燃烧费用（= 付费预订容量，市场行为而非攻击）。新模型死锁由上架质押转化的引导权重解决。均衡预期为幂律：少数开源旗舰占多数副本，长尾靠质押维持。

### 6.3 stake 的角色：容量门控 + 有界调节 + 保真押金

容量（驻留）永远是硬门控——零容量零票，stake 再多无用。在此前提下，质押经 `√(stake)/√(上限)` 缩放中签阈值：次线性（翻倍影响力需四倍质押）、硬封顶（超上限的巨鲸与刚到顶者等权）、零总质押时优雅退化为纯容量共识。同一笔质押兼作**保真押金**：TEE 引入的两处可信断言（`m_t` 自报、TEE 破裂时的伪造）由罚没威慑——Subspace 无需 stake 因为它不信任任何人；PoRW 在信任 TEE 的精确位置配上 skin-in-the-game。

## 7. 端到端 agent 生命周期

| 生命周期步 | 承载 | 证明 |
|---|---|---|
| 感知（读记忆） | 存储轨 | 永存 + 信封加密，明文仅在 attested CVM 内解开 |
| 思考（推理） | 显存轨 | 驻留（C）+ 设备（B） |
| 行动（产出） | 推理证明 | D：输出确由注册模型产生 |
| 记忆（写记忆） | 存储轨 | 永存 + memory root 上链 |
| 身份 | CVM | 节点密钥永不出 TEE |

由此获得中心化平台给不了的性质：**agent 可暂停、可复活**——全部状态独立于任何服务商，停用多年后任何节点拉取记忆、加载注册模型即原地复活。记忆永存 + 算力按需 + 输出可验证 = 链原生的永生 agent。经济上 agent 的代币消耗是"生存开销"（写记忆 + 做推理），两轨费用流各自闭环。

## 8. 实测验证（A100 80GB PCIe，2026-08）

原型（开源于本仓库 `porw-poc/`）实现了 sketch 规范、vLLM `fused_moe_kernel` 结构复刻的融合内核与定向扫描内核，一键脚本从干净机器完整复现：

- **正确性 11/11**：CPU 解释器、GPU 原生后端与 numpy 参考实现逐位一致；覆盖语义（冷专家不计票、batch 组成不变性、融合与扫描逐 tile 一致）全部验证。
- **攻击演示**：tile 级常数系数被 4 字节摘要 100% 伪造（证明字粒度系数是硬要求）；字粒度方案下压缩攻击者与泛函重构攻击者全部失败；单比特篡改必检出。
- **性能**（原生 u32 算术，1.07 GB 权重压穿 L2 的真实 HBM 流式形态）：定向扫描 **1401 GB/s = 72% HBM 峰值**——每 slot 审计 70GB 权重约 50ms，**约 5% 带宽税**；融合内核开销 2.7–8.7%（作为加固模式可行）。

## 9. 威胁模型与诚实边界

- **TEE 被攻破**：伪造 sketch 被副本核验 / 存储轨终审抓获罚没；虚报 `m_t` 被硬件包络封顶（有界通胀，上限为省电收益）；权重外置被物理时差排除（HBM 直读 ~24ms vs PCIe 流式 1.25s）。设备证书链根级泄露属系统性风险，走治理吊销 + 降级路径。
- **即时租卡**：注册 bond + epoch 生效延迟（接替 Subspace"plotting 慢"的角色）+ 权重需先经 DSN 获取。
- **长上下文刷量**：KV cache 不是注册权重，attention 读取不计票，此路不通。
- **主轨硬件门槛**：机密计算为数据中心卡专属（Hopper 起）；消费卡走降级平行彩票（较低权重），保持长尾去中心化。TEE 信任崩塌时治理可将共识权重滑向纯经济-物理防御模式，保留回退经典 PoAS 的终极选项。
- **永存语义**：经济-概率性，链活数据在；不承诺绝对永存。

## 11. 相关工作

**Filecoin**：密码学密封 + 双副本换可检索——PoRW 用 TEE 免掉密封，显存零冗余。**Bittensor / io.net 类**：无硬件证明或仅软证明，计量依赖委员会评分——PoRW 的票权与字节驻留有物理绑定。**TOPLOC 类可验证推理**：激活值哈希 + 重算验证，受浮点不可复现所困——D 支柱以 TEE 信任根绕过重算，与此类方案正交可叠加。**Phala / Atoma 等 TEE-ML**：已验证 TEE-GPU 推理出证明的工程可行性——PoRW 的差异在把它接入 Nakamoto 式容量抽签共识，而非仅做任务级验证。**Subspace/Autonomys**：本设计的骨架来源；PoRW 是其共识资源在 AI 时代的重定向，而非替代——存储轨即原 Subspace。
